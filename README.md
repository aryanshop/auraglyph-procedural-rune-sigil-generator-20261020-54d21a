# AuraGlyph: Procedural Rune & Sigil Generator

AuraGlyph is a specialized browser-based creative tool and sacred geometry generator. It translates words, intentions, and initials into symmetric vector runes and ritual sigils with customizable grid complexity, symmetry rules, metallic color palettes, and export capabilities.

## Features
- **Intent-Driven Seeds**: Automatically calculates numeric vibrations and checksums from typed words or intentions.
- **Symmetry Engines**: Radial (4, 6, 8-fold), axial mirror reflection, and freeform organic modes.
- **Customizable Elements**: Toggle anchor nodes, orbital rings, protective outer borders, and decorative rune ticks.
- **Metallic Color Themes**: Ancient Gold, Celestial Silver, Mystic Emerald, Obsidian Neon, and Crimson Ritual.
- **Export Utilities**: Instantly export high-resolution PNG images or custom SVG vector wrappers.

## Local Run Instructions
1. Download or clone all project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No server setup, external dependencies, or build tools required.

## Technical Notes
Built entirely with vanilla HTML5 Canvas, modern CSS grid/flexbox, and ES6 JavaScript. Operates 100% offline with zero external network requests or data collection.
